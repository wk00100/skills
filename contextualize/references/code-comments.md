# 程式碼註解的選字延伸

contextualize 的選字規則照用；程式碼註解這個對象額外注意：

1. **識別字不翻譯**：變數／函式／型別名、API 名、錯誤字串保留原文，別為了「在地化」去翻 identifier。
2. **中文註解也會有翻譯腔**：依中文母語者實際會怎麼講來寫，不要逐字轉英文語序（「回傳一個包含使用者的陣列」→「回傳使用者陣列」）。
3. **語域可比正文鬆**：註解允許口語、簡寫，只要不歧義；不必硬套正式譯法。
4. **概念名與 code 對齊**：註解提到的概念要和 identifier 對得起來，別註解叫「快取」而變數叫 `buffer`。

（B 面「該不該有、說什麼」見 `operationalize/references/code-comments.md`）
