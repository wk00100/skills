# Contextualize：依語境重選用字

## 前提

一個原文詞不對應一個固定中文詞。`authoritative` 的核心不是「權力」，是「值得信賴、可作依據」；中文「權威」帶「地位高、說了算」的權力意味，語意其實比原文重。把一詞死鎖成一譯 → 翻譯腔、選錯語域。正確做法：**先判這裡強調什麼，再選貼合的字**；同一詞在不同句可以不同譯。

這支是 [operationalize](../operationalize/SKILL.md) 的姊妹——那支把模糊形容詞**收斂**成單一規格，這支反過來，破除死板對應、依語意**分流**選字。

## 觸發模式（先分清楚）

- **被動觸發**（在別的工作中因語意匹配自動套用）：直接改，不問。
- **主動觸發**（使用者明確叫 `/contextualize` 或指名要處理用字）：先問要「建議清單」還是「直接修改」，得到答覆再動手。

## 選字規則

1. **抓可疑詞（跑三道檢驗，命中任一即換）**：
   - **壓縮**：常見複合詞被砍成自造縮略？（判準←判斷標準）→ 展開回標準詞。
   - **calque**：外文字面直翻、母語者講同概念不會這樣說？（衛生←hygiene、information→信息）→ 換母語實際用詞。
   - **語意重量**：中文連帶意涵比原文強或窄？（authoritative→權威、robust→強壯）→ 依語意分流（見下）。
2. **判語意**：原文這裡強調的是「可信」還是「地位」？「官方認定」還是「最終依據」？
3. **依語意分流選字**，別回填同一個字。以 `authoritative` 為例：

   | 原文語意 | 譯法 |
   |---|---|
   | 可信、可靠 | 可信來源／可靠來源 |
   | 官方認定 | 官方來源／官方文件 |
   | 最終依據（source of truth） | 主要依據／單一事實來源／基準來源 |
   | 具公信力 | 具公信力的來源 |
   | 地位、定論 | 權威 |

4. **允許同詞多譯**：同一原文詞在不同句依語意給不同中文，這是正確不是不一致。
5. **標記不轉換區**：`## 背景`、`**Why:**`、比喻與敘事段原文保留。

## 不要改的東西

- 語意上「權威」確實最貼的（強調地位、不容爭議的定論）——保留，別為了避嫌硬改成「可信」。
- 只處理**可疑的固定對應與翻譯腔**，不是把所有正式詞都改白話、也不是把所有詞都換掉。

## 程式碼註解

處理程式碼註解時，加讀 `references/code-comments.md`（註解選字的額外細則）。

## 輸出

- **被動觸發**：直接產出改寫後文件，不逐處加註解。
- **主動觸發**：先確認模式；選「建議」就列「原詞 → 建議譯法（＋一句理由）」，選「直接改」才動文件。
- **自檢**：每個被改的詞都能講出「原文這裡強調 X，所以選 Y」；換後的詞通過「同行不需解釋即懂」＋「一詞一義」兩關；WHY 區塊與原文 diff 為零。
